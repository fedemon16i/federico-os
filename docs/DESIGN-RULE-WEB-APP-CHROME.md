# Regla — chrome de navegador (UI web app)

Fecha: 2026-08-28

Toda superficie que sea **UI de web app** se muestra *dentro de un navegador*:

- traffic lights: cerrar / minimizar / maximizar
- barra de dirección (URL de producto, no dominio real confidencial)
- el contenido de la app vive debajo, no flota en el vacío

Aplica a: EY Fabric (home, catálogo, services, workbench, hub, publisher, user flow, design canvas cuando es app).

No aplica a:

- mobile / phone (Chek, Blockchain)
- diagramas (Measure sitemap, Research lab, Understand findings)
- gráficos (funnel de Analyze)

Una secuencia de pantallas web = un navegador que cambia de URL/contenido.
Un gráfico o mapa = pieza suelta, sin ventana de browser.
